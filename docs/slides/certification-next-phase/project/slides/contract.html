The contract

The Bruno collection joins the two systems

What it carries

  • The endpoints to call, in a fixed order
  • The parameters for each request
  • The expected response for each record
  • Which fields are checked, and how values are compared
  • A manifest and a readiness report

How Admin App runs it

  • Unchanged, exactly as uploaded
  • Admin App supplies the API address and access token
  • Uses the Bruno CLI version pinned in the manifest
  • Sorts results by result kind: pass, value mismatch, record not found and others
The generator PRD owns the contract, contract terms C1 to C11. Admin App never edits or re-derives the collection; the token never lands in a file. A change to the contract is versioned on both sides.
