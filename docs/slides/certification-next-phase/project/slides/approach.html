The approach

Three concerns, three PRDs

Generator PRD

Bruno Assertion Model Generator

Offline tool run by an Ed-Fi representative

The contract

Bruno collection

Endpoints, parameters, expected responses

Admin App 4.2 PRD

Admin App

Runs, review and decisions

Automation Platform PRD

Underneath everything: hosting, identity, vendor environments, run execution, artifact storage

Each PRD has one job. The generator turns a vendor’s mapping into a Bruno collection. Admin App runs that collection and handles review. The platform provides the infrastructure under Admin App. The collection is the only thing the generator and Admin App have to agree on.
